# Proje Yazarı: Sinem Güraslan

# Projenin Adı: Kod-Asistan v0.1

## Projenin Amacı
Kullanıcılara günlük işlerinde (hesaplama,
selamlama vb.) yardımcı olacak bir dijital
asistan tasarlamak.

## Projenin Hedefleri
- v0.1: Kullanıcıyı selamlama
- v0.2: Basit matematiksel hesaplamalar yapma
- v0.3: Akıllı menü oluşturma
- v0.4: Kullanıcı bilgilerinin saklanması
- v1.0: Gelişmiş dijital asistan oluşturma
